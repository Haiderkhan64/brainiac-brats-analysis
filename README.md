# BrainIAC on BraTS: analysis code, split and results

Analysis code and result files for the paper **"How Much Does Pretraining Add? A Controlled Audit of the BrainIAC Brain-MRI Foundation Model"** (Medical Image Analysis submission).
The study compares frozen, LoRA and full fine-tuning of the BrainIAC ViT-B encoder, and random-initialisation
baselines, for whole-tumour segmentation on BraTS 2023 GLI, BraTS-PEDs and BraTS-Africa.

**DOI:** each release is archived on Zenodo; the DOI of a version is shown on its Zenodo record and in the paper.

## What is in this repository

| Path | Content |
|---|---|
| `scripts/clean_tables.py` | Two-level bootstrap CIs, per-seed paired t-tests, Holm correction |
| `scripts/failure_decomposition.py` | Splits each mean difference into failed-case and non-failed-case parts |
| `scripts/export_results.py`, `export_split.py` | How the CSVs below were produced from the private run logs |
| `scripts/make_clean_test_list.py` | Derives the excluded GLI test cases (patient also in train/val) |
| `splits/case_level_split.csv` | Case IDs and their train / val / test assignment (IDs only) |
| `splits/test_excluded.csv` | GLI test cases excluded from the primary analysis |
| `results/all_66_runs_exact.csv` | One row per run: exact Dice, HD95 (mm), calibration summaries |
| `results/per_case_metrics.csv` | One row per run and test case: Dice and HD95 (mm) |
| `tables/` | Output of the scripts (regenerated by the commands below) |
| `tests/smoke_test.py` | Runs the statistics on synthetic data and checks they behave |

## What is not included

* **No BraTS images, segmentations or derived arrays.** Obtain BraTS 2023 from Synapse and BraTS-Africa from TCIA under their
  terms. Only case identifiers and our own result tables are shared.
* **No BrainIAC code or checkpoint.** Get them from the BrainIAC repository under its licence (research use). The commit and
  checkpoint used: `ba60f45bed832ee0e5683c678caeaeefe2072f0d`, `BrainIAC.ckpt`.
* **No training code.** It is available from the corresponding author on reasonable request. Every setting needed to retrain is
  listed in the paper (preprocessing, split, schedule, learning rates, LoRA configuration, augmentation, precision).

## Reproducing the tables

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python tests/smoke_test.py            # sanity check on synthetic data

python scripts/clean_tables.py \
    --per-case results/per_case_metrics.csv \
    --exclude splits/test_excluded.csv \
    --B 100000 --out tables

# the same statistics on all 250 GLI test cases (appendix sensitivity analysis)
python scripts/clean_tables.py \
    --per-case results/per_case_metrics.csv \
    --B 100000 --out tables

python scripts/failure_decomposition.py \
    --per-case results/per_case_metrics.csv \
    --exclude splits/test_excluded.csv \
    --fail-thresh 0.1 --out tables
```

Outputs: `tables/means_primary_clean221.csv`, `tables/contrasts_primary_clean221_B100000.csv`, `tables/means_primary_all250.csv`,
`tables/contrasts_primary_all250_B100000.csv`, `tables/failure_decomposition_thr0.1.csv`. The bootstrap uses `--rng-seed 0` (default), so results are exactly repeatable
with the pinned package versions.

## Statistical methods (as implemented)

* **Paired difference.** For a contrast A - B at a given training size and dataset, each seed gives one Dice per test case for
  A and for B. The same seed uses the same training subset for every strategy, so differences are paired by seed and case.
* **Two-level bootstrap.** Each replicate resamples seeds with replacement, then test cases with replacement, and averages
  the paired differences. The 95% CI is the 2.5th to 97.5th percentile of 100,000 replicates.
* **Per-seed t-test.** A one-sample t-test on the per-seed mean differences (n = number of seeds).
* **Holm correction.** One family per metric: the 24 pretraining contrasts (3 datasets x 4 training sizes x {`frozen - rand_frozen`, `full - rand_full_matched`}). Strategy contrasts (`lora - frozen`, `full - frozen`) and the tuning-sensitivity contrast (`rand_full_matched - rand_full_UNTUNED_mult1`) are reported without Holm adjustment (`p_holm` is empty).
* **Sensitivity intervals.** `ci_case_only_*` is a case-only bootstrap of the seed-averaged difference (`--B-case`, default 5,000 replicates; ignores seed variance, too narrow). `ci_seed_t_*` is the per-seed t interval with seeds - 1 degrees of freedom.
* **Test sets.** GLI primary results use the 221 test cases left after excluding cases whose patient also appears in
  training. PEDs (99 cases) and Africa (146 cases) use all labelled cases.
* **Failures.** A run-case counts as a failure when Dice < the `--fail-thresh` value; the threshold is stated in the paper.

## Data format

`results/per_case_metrics.csv`: `run, strategy, n_train, seed, dataset, case_id, dice, hd95_mm`
(`dataset` is `GLI`, `PEDs` or `Africa`; HD95 is in mm on the 96^3 grid, with an empty prediction scored as the grid diagonal).
Strategies: `frozen, lora, full, rand_frozen`, and three random-init full fine-tuning controls: `rand_full_UNTUNED_mult1` (88 and 876 cases, encoder LR multiplier 1), `rand_full_matched` (5 and 20 cases, same multiplier as `full`) and `rand_full_tuned` (88 and 876 cases, same multiplier as `full`). `rand_full_matched` and `rand_full_tuned` are the same control logged under two names; the analysis scripts merge them into `rand_full_matched`, so the contrast `full - rand_full_matched` exists at all four training sizes.
